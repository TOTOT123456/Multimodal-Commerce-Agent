# 向量训练与检索全链路

## 结论

项目从训练定义开始把显式负例纳入 Embedding 选型。五种 recipe 使用同一开发集和三个随机种子比较，最终 canonical 为：

```text
BAAI/bge-large-zh-v1.5
  + easy2 显式负例
  → BM25/Vector RRF（N=40, vector_weight=0.8, rrf_k=5）
  → 一级 Top-20
  → BAAI/bge-reranker-v2-m3（mixed_typed3_mined4）
  → 二级 RRF（source_weight=0.4, rrf_k=8，候选域严格为上述 20 个）
  → Planner Top-10
```

唯一机器可读入口是 `PROJECT/configs/retrieval_canonical_route.json`。

本报告的叙事主线以 **Legacy frozen 6,000** 为最终端到端口径：它同时拥有检索指标和固定 Planner 回放结果。cross-style dev 只用于选模与选参，不作为最终成绩；Round-final 和 API frozen 作为补充检索/回归证据。

## 2. Embedding 训练目标

对一个 query $q_i$、正样本文档 $d_i^+$ 和显式负例集合 $N_i$，MNRL 使用相似度分数 $s(q,d)$：

$$
\mathcal{L}_{MNRL}
=
-\frac{1}{B}\sum_{i=1}^{B}
\log
\frac{\exp(s(q_i,d_i^+)/\tau)}
{\exp(s(q_i,d_i^+)/\tau)
+\sum_{j\ne i}\exp(s(q_i,d_j^+)/\tau)
+\sum_{d^-\in N_i}\exp(s(q_i,d^-)/\tau)}.
$$

Batch 内其他正样本文档继续提供 in-batch negatives；`easy2/hard2/all4` 额外把结构化 `neg[]` 放入分母。梯度累积只扩大优化器有效 batch，不会跨 micro-batch 合并 in-batch negative 池。

## 4. Embedding 冻结后的下游选择

Embedding 与 Reranker 的梯度训练彼此解耦，但候选分布、候选深度和两级 RRF 与 Embedding 输出相关。因此冻结 `easy2` 后依次完成：

1. 一级 BM25/Vector 融合的 1,190 组网格搜索；
2. 四种 Reranker 架构的学习率筛选和三随机种子比较；
3. 三种 Reranker 负例 recipe；
4. 获胜负例 recipe 与架构第二名的交互检查；
5. Reranker 深度 `R=10/20/30/50` 与 Planner 深度 `P=5/10/20/30/50` 的一致性联合比较，约束 `P≤R`，每格搜索二级 RRF；
6. 深度锁定为 R20/P10 后，对二级 Source/Reranker RRF 完整跑 110 组有限网格与独立 sealed confirmation。

### 4.1 一级搜索漏斗

`candidate_n` 是 BM25 和 Vector 各自进入一级 RRF 的深度；它与送入 Reranker 的 `candidate_k` 不是同一个参数。

| 未裁剪 Pareto 前沿 | 按 A@10/20/30/40/50 与 MRR 做 coverage 非支配筛选 | **80** | 保留不同深度目标的强候选 |
| 联合搜索输入 | 每深度 Top-5 保护后按统一规则 cap | **24** | 进入 Reranker 候选深度与二级 RRF 联合搜索 |

### 5.2 easy2 + v2-m3 正式 Badcase 审计

分析对象是 Legacy frozen 6,000 条的最终 Top-10。严格 badcase 定义为“至少一个 gold tool 不在最终 Top-10”；非 gold 工具进入 Top-10 本身不算错误，只有其挤出 required tool 时才作为竞争信号。

| 项目 | 结果 | 解释 |
|---|---:|---|
| 最终 Top-10 失败 | **158 / 6,000（2.6333%）** | 对应 5,842 条完整覆盖 |
| 至少一个 gold 在一级 Top-20 外 | **30 / 158** | 一级覆盖/候选截断失败 |
| 所有 gold 已在一级 Top-20、但最终 Top-10 失败 | **128 / 158** | 候选域内的融合/前缀排序失败 |
| 每条仅漏 1 个工具 | 158 / 158 | 共 158 个漏召工具实例 |
